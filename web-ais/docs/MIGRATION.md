# Карта миграции из Excel в Web

## Разделы приложения

| Excel-лист | Web-раздел | Назначение |
| --- | --- | --- |
| `База` | Слушатели | заявки, статусы, обучение, оплаты, документы |
| `Реестр договоров` | Договоры | договоры, сроки, суммы, контрагенты |
| `Реестр программ` | Программы | каталог программ, цены, часы, статусы набора |
| `Учебные планы` | Учебные планы | дисциплины, часы, преподаватели, аттестация |
| `Вебинары` | Вебинары | регистрации, оплаты, ссылки подключения |
| `Прямые затраты` | Прямые затраты | расходы по конкретным слушателям и актам |
| `Общие затраты` | Общие затраты | общецентровые расходы |
| `Запасы` | Запасы | ТМЦ, остатки, связь с uid |
| `Настройки` | Справочники | статусы, виды договоров, формы обучения, роли |

## VBA-модули для переноса

| Модуль | Что переносить |
| --- | --- |
| `Main` | основные команды, переходы, расчеты, операции над карточками |
| `КарточкаСлушателя` | форма слушателя, проверки, документы, статусы |
| `КарточкаКонтрагента` | карточка партнера/контрагента |
| `ИмпортЗаявок` | загрузка заявок из внешних источников |
| `Настройки` | сохранение параметров и справочников |
| `WhatsApp_BOT` | коммуникации и уведомления |
| `FTP`, `JupiterSync` | обмен файлами и синхронизация |
| `JSON`, `API` | вспомогательные интеграции |

## Целевая серверная архитектура

1. Frontend: текущий SPA можно перенести на React/Vue или оставить vanilla JS для внутреннего контура.
2. Backend: REST API для сущностей, ролей, аудита, документов, уведомлений.
3. База данных: PostgreSQL или MS SQL Server.
4. Файлы: отдельное хранилище для сканов, договоров, актов, документов об обучении.
5. Авторизация: роли `Администратор`, `Менеджер`, `Методист`, `Бухгалтер`, `Преподаватель`.
6. Импорт: отдельный загрузчик `.xlsb/.xlsx`, который сохраняет исходные uid и номера документов.
