# Отчетность: 1-ПК

Раздел доступен администраторам и менеджерам. Вычисления выполняются в браузере над текущим полным снимком разрешённой пользователю базы, независимо от фильтров таблиц. Данные не отправляются в Росстат и не записываются обратно в карточки. Оба результата — `.xlsx`.

## Источники и правила

- Годовая форма: предоставленный пользователем `Форма 1-ПК (2025)_исх.xls`. Сохраняются 45 листов, оформление, области печати, проверки, примечания и формулы Excel. Файл не заменяет проверку актуальности формы перед официальной подачей.
- 1 369 SQL-примечаний разделов 1.3, 2.1, 2.2, 2.3.1, 2.3.2, 2.4 и 2.5 переведены в ограниченный интерпретатор без `eval`, произвольного SQL или подключения к указанному в шаблоне Excel-источнику.
- Условие `Настройки!B5`: номер бланка заполнен, программа КПК/ППП, **дата отчисления ИЛИ дата окончания** входит в выбранный период. Состояние текущего статуса не добавляет ограничений, которых не было в исходном условии. Единица учёта — запись об обучении, не уникальное ФИО по всем программам.
- Возраст для годового раздела 2.4 рассчитывается из даты рождения на **1 января следующего года**, согласно заголовку формы. Пол берётся из карточки, не угадывается по имени.
- Среднегодовая численность воспроизводит длительность в днях / 30 / 12; при пустых сроках — 14 дней для КПК и 180 для ППП по примечанию. Округление половин — к чётному, как в Access ROUND. Используются полноценные даты АИС, без укорачивания четырёхзначного года выражением `mid(...,1,8)` из старого Excel.
- Квартальный отчёт повторяет таблицу из `1-ПК квартальные.docx`: КПК/ППП, всего и женщины, возраст от 15 лет. Возраст — на конец периода. Условия отбора выданных документов взяты из годовой формы. Начало — 1 января, конец — последний полностью прошедший квартал, часовой пояс Москва. В январе–марте текущего года выгрузка недоступна; для прошедшего года учитываются все четыре квартала.

## Выбор периода и индикатор

Для квартального отчёта список «По квартал включительно» сразу показывает автоматически определённый последний завершённый квартал по Москве. Можно выбрать любой завершённый квартал выбранного года; расчёт остаётся нарастающим итогом с 1 января. При смене года автоматически определяется новый квартал. Незавершённые кварталы недоступны. Выбор меняет данные, заголовок и имя Excel-файла; прежний результат сбрасывается до повторного расчёта. Ручные значения сохраняются в сеансе отдельно для каждого периода.

Расчёт и упаковка Excel выполняются в отдельном Web Worker. Интерфейс показывает текущий этап, фактическое количество обработанных показателей/листов, а для этапов без измеримого объёма — динамичный индикатор и прошедшее время. Кнопка «Прервать» завершает worker на любом этапе, в том числе при выгрузке, не изменяя базу. После отмены выгрузки рассчитанные значения остаются доступны для повторного скачивания.

## Неполные данные и ручные ячейки

Состав реестра, связь с программой, дата рождения, пол и необходимые классификаторы проверяются. Предупреждения выводятся до выгрузки; выгрузка с ними требует подтверждения. Отсутствующие даты рождения исключают запись из квартального показателя; неизвестный пол не учитывается как женский. Неизвестная или повреждённая формула останавливает расчёт с адресом ячейки.

Статистические ячейки без SQL-примечаний не выдаются за рассчитанные показатели: старые значения удалены, поля остаются для ручного ввода в разделе или Excel. В частности, кадровые, имущественные и финансовые сведения нельзя вывести из базы слушателей без дополнительных правил. Ручной ввод относится только к текущему снимку и не меняет базу. Повторный расчёт сохраняет введённые в этом сеансе ручные значения для того же вида отчёта/года.

## Сборка и безопасность шаблонов

`scripts/convert-pk-template.ps1` открывает исходный XLS только для чтения, с отключёнными макросами, событиями и обновлением связей, и создаёт отдельную копию XLSX. Это одноразовый этап разработки: экспорт отчётов не требует установленного Excel или сетевого диска.

`scripts/build-pk-report-templates.mjs` использует bundled `@oai/artifact-tool` для квартальной формы. Для годовой сохранены исходные OOXML-части: пересоздание старой многостраничной формы потеряло бы проверки/объекты и настройки печати. Генератор удаляет прошлогодние показатели, неиспользуемые общие строки, внешние Excel-связи, макрокоманды и метаданные автора, сохраняет формулы примечаний. Исходные файлы и база не изменяются. В публичный пакет не включаются исходная база, путь подключения или персональные данные слушателей.

`pk-report-templates.js` — сгенерированный ресурс. Для пересборки укажите `AIS_ARTIFACT_MODULES` (путь bundled Node modules), запустите builder с путём к конвертированной копии. Не редактируйте base64 вручную.

## Проверки

`node web-ais/scripts/test-pk-reporting.js [каталог_для_синтетических_xlsx]`

Проверяются все 1 369 запросов, границы кварталов по Москве, оба типа программ, женщины, возраст, связь с реестром, отсутствие бланка, удалённые записи, остановка расчёта, восстановление зависимых значений Excel, сохранение комментариев и объединений. Визуальная проверка выполняется по синтетическим Excel-файлам, без записи отчёта на основе живой базы.
