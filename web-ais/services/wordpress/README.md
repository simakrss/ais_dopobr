# Генератор образовательных программ

Генератор создаёт черновик лендинга из опубликованной программы edu-plus.ru и виртуальный товар WooCommerce на zifra-plus.ru. Поддерживаются ПРО, ДОП, КПК и ППП. Только для ПРО ссылка встречи SberJazz вводится вручную на вкладке «Сайт»; аккаунт/API Jazz не требуется. ДОП, КПК и ППП не создают скачиваемый файл и не требуют даты/времени вебинара или ссылки подключения.

## Установка (требует отдельного разрешения владельца сайтов)

Служебный MU-модуль не включается обычной публикацией АИС. После согласования и коммита:

```powershell
& .\web-ais\scripts\deploy-lms.ps1 -ProgramSites
```

Сценарий использует существующий локальный FTP-профиль через штатный механизм публикации. Он устанавливает только `wp-content/mu-plugins/ais-program-generator.php` двух указанных сайтов, генерирует два независимых ключа и сохраняет их вне `public_html`. Настройки WordPress и существующие страницы/товары не изменяются. Повторная установка сохраняет ключи, несовпадение останавливает установку. Частично установленный модуль без ключа закрыт для подписанных запросов; повторный запуск завершает установку.

- WordPress: `/edu-plus.ru/ais-program-site.key`, `/zifra-plus.ru/ais-program-site.key`.
- Сервер АИС: `/edu-plus.ru/lms-runtime/data/program-site-keys.json`.
- Локальная АИС: `web-ais/storage/program-site-keys.json` (исключён из Git).
- Временные локальные файлы ключей находятся только в игнорируемой `.runtime/program-sites/`.

Не помещайте ключи и пароли WordPress в Git, браузерные настройки или HTML. Административные пароли сайтов генератор не хранит. При утрате доверия к машине сначала отзовите её доступ, затем согласованно замените соответствующие ключи на обеих сторонах.

## Работа

1. В карточке программы заполнить вид, название, часы, стоимость, срок, новый свободный код лендинга и HTML-описание на вкладке «Сайт». Для ПРО дополнительно нужны дата, время по Москве, полная ссылка SberJazz и сведения о спикере. Для длинного названия программы указать короткое название товара (до 128 символов). Для ДОП/ПРО требуется английское название, для КПК/ППП — учебный план. Дата в образцах для курсов по умолчанию текущая (Москва), при необходимости задаётся отдельно; она не меняет сроки обучения слушателей.
2. «Создать на сайте» сохраняет карточку и открывает мастер. Выбрать опубликованный прототип; поиск выполняется только по названию.
3. «Подготовить черновики»: копируются ACF-поля, вложенные повторители, изображения и публичные рубрики прототипа. Отзывы в `blok_opisaniya_kursa` и полях `review`/`otzyv` берутся непосредственно из исходного лендинга: цитаты, фотографии и ссылки не заменяются. Обновляются название, цена одного предложения, часы, дата, описание, автор (если задан), учебный план и ссылки регистрации. Исходный прототип не меняется.
4. Автоматически формируются образцы из настроек конструктора: «Сертификат ПРО», «Сертификат ДОП», «Удостоверение о повышении квалификации» или «Диплом о переподготовке». Для сертификатов — RU/EN, для удостоверения/диплома — основной документ и все страницы приложения (3–8 страниц). Используются только данные программы, идентичность ОБРАЗЕЦ/SAMPLE и водяной знак; слушатели и счётчики выдачи не изменяются. Публично загружаются JPEG, не исходные DOCX/PDF. В локальном режиме шаблоны читаются с локального диска; серверная генерация может использовать существующий локальный шлюз PDF/OCR.
5. Войти в WordPress и проверить черновики и все ссылки на образцы. Отзывы, фотографии и неизменённые дополнительные блоки могут относиться к прототипу. Изменения собственных черновиков в WordPress сохраняются при повторе с теми же параметрами; новая подготовка изменённых параметров заменяет их содержимое.
6. Подтвердить проверку и опубликовать. Отображаются результат, ID товара/лендинга, ссылки и промосообщение, сохраняемые в карточке АИС. Товар перенаправляет на `/other_course/<код>/` для ПРО/ДОП, `/courses-pk/<код>/` для КПК, `/courses-pp/<код>/` для ППП. Для КПК/ППП предлагаются прототипы соответствующего раздела; для ДОП доступны все три раздела. Для ПРО подключение доступно через штатную ссылку скачивания заказа WooCommerce, только после проверки разрешения.

Файл подключения HTML хранится в приватной папке `ais-webinar-files/<идентификатор>/connection.html` вне корня сайта; он регистрируется как скачиваемый файл товара. Модуль перенаправляет авторизованное скачивание на SberJazz. Общедоступное правило `?download_file=ID* → Jazz` намеренно не создаётся: оно обошло бы проверку заказа. Другие товары и скачивания не затрагиваются.

Если прервалась связь, повторить действие с теми же параметрами. Программа имеет постоянный ключ, операции защищены блокировкой базы WordPress; повторный запуск не создаёт новые копии. Несовпадение версии программы запрещает публикацию до новой подготовки. Опубликованные объекты с изменёнными параметрами автоматически не перезаписываются.

## Ограничения первого этапа

Создание самой встречи, изменение четырёх вебинаров главной страницы, настройка списка получателей, согласование со спикером, рекламная рассылка, тестовая оплата и обновление приказа о наборе выполняются отдельно. Для вариантов одной программы существующий код лендинга в карточке сохраняется, но создание новой страницы по занятому адресу запрещено: существующая страница не должна быть молча заменена. Изменения шаблона, формул, названия, параметров или учебного плана требуют повторной подготовки образцов. Публикация проверяет принадлежность и наличие всех файлов, включая страницы приложения в галерее.

Перед первым реальным запуском после установки проверить `/api/program-sites/health` под администратором АИС (без учётной записи — 401), затем прототип, собственные черновики и публикацию на согласованной тестовой программе. До этого нельзя считать интеграцию проверенной на рабочих сайтах.

## Проверки без рабочих данных

```text
node web-ais/scripts/test-program-site-generator.js
node web-ais/scripts/test-program-site-certificates.js
php web-ais/scripts/test-program-site-wordpress.php
node web-ais/scripts/test-program-site-generator.js --serve
```

Последняя команда открывает изолированный loopback-стенд с тестовыми данными и подменёнными сетевыми вызовами; она не обращается к рабочим WordPress или общей базе.
